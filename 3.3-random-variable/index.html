確率変数の性質

期待値・分散・共分散・確率変数の線形結合を理解します。

このモジュールで学ぶこと 「テストの点数を全員に10点プラスしたら、平均と分散はどう変わる？」「男女の身長を合計した確率変数の分散は？」確率変数を変換したり足したりするとき、期待値・分散がどう変化するかを知っていれば、複雑な計算を公式一本で処理できます。このモジュールでは確率変数の「操作のルール」を学びます。 期待値と分散の変換規則 あるクラスの数学テスト（平均60点・分散100）の点数を全員に +10 点し、さらに ×2 倍にすると、平均と分散はどうなるでしょうか？ 定数 a,b を使った変換 Y=aX+b に対して：
E[aX+b]=aE[X]+b
V[aX+b]=a2V[X]
この例では Y=2X+10 なので E[Y]=2×60+10=130、V[Y]=22×100=400 です。重要なのは「定数の加算（+b）は期待値だけを動かし、分散には影響しない」という点です。散らばりは全員同じだけずらしても変わりません。一方、係数倍（a 倍）は期待値を a 倍、分散を a2 倍にします（標準偏差は ∣a∣ 倍）。 V[aX+b]=a2V[X]：定数の加減算は分散に影響しない。係数は分散に2乗で効く。 共分散と相関係数：2変数の「関係」を数値化する 前のモジュールまでは単一の確率変数を扱ってきました。では2つの確率変数 X（身長）と Y（体重）が同時に変動する場合、その「関係の強さ」はどう測るでしょうか？ X が平均より高いとき Y も平均より高くなりやすくなります。この「一緒に動く傾向」を数値にしたものが共分散です：
Cov(X,Y)=E[(X−μX​)(Y−μY​)]=E[XY]−μX​μY​
正の共分散は「同じ方向に動く傾向」、負は「逆方向」、ゼロは「線形の関係なし」を意味します。ただし共分散は単位（cm×kg など）を持つため、-1〜1 に標準化した相関係数で比較するのが一般的です：
ρ=V[X]V[Y]​Cov(X,Y)​
ρ は −1≤ρ≤1 で、∣ρ∣ が1に近いほど線形の関係が強いことを表します。 共分散の計算式：Cov(X,Y)=E[XY]−E[X]E[Y]。期待値の公式から導ける実用的な形です。 確率変数の和の期待値と分散 「男性の身長 X と女性の身長 Y を足した X+Y の期待値・分散は？」このような確率変数の和の統計量も、公式で求められます。 まず期待値について。これは独立性に関わらず常に成り立ちます：
E[X+Y]=E[X]+E[Y]
分散については共分散が関係します：
V[X+Y]=V[X]+V[Y]+2Cov(X,Y)
X と Y が独立な場合は Cov(X,Y)=0 となり、分散は単純に足し算できます。直感的には「互いに無関係なばらつきを合算すると、それぞれのばらつきが積み上がる」という意味です。差の分散 V[X−Y] は共分散項の符号が逆になり V[X]+V[Y]−2Cov(X,Y) となります。 独立な確率変数の和の分散：V[X+Y]=V[X]+V[Y]。差 X−Y の分散でも符号に注意して同様に計算。 よくある誤解・つまずき 和（差）の分散を足せるのは「独立」のときだけ。 独立でなければ共分散の項が加わります。 差でも分散は足します。 独立なら V[X−Y]=V[X]+V[Y]（引き算ではない）。 定数倍と定数加算の効き方が違う。 V[aX+b]=a2V[X]。定数 b は分散に影響しません。 ここまでのまとめ 期待値の線形性：E[aX+b]=aE[X]+b。 分散：V[aX+b]=a2V[X]（定数加算は分散に効かない）。 独立なら和・差の分散は V[X]+V[Y]（共分散0）。

確認クイズ（抜粋）

Q1. E[3X+2] を E[X]=5 のとき求めよ。

A. 17

Q2. V[2X−1] を V[X]=9 のとき求めよ。

A. 36

Q3. X と Y が独立のとき V[X+Y] はどれか（V[X]=4、V[Y]=9）。
